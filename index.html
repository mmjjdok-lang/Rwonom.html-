توثيق الأنظمة والأساليب البرمجية المنفصلة لمكتبة الواجهات

1. شاشة التحميل (Splash Screen)

شاشة البداية المنفصلة التي تنتظر حتى تنتهي قبل بناء النافذة الرئيسية.

splash.lua 
local splash = Library.Splash({
    Text = "اسم شعارك", 
    Font = "Bangers", 
    Color = "Cyan",
    BackgroundColor = "Dark", 
    Size = 200, 
    TextSize = 40,
})
splash:Wait()

2. النافذة الرئيسية والوسم (Window & Tag)

إنشاء النافذة الأساسية للسكربت مع تحديد الوسم وإصدار النسخة.

window.lua 
local Window = Library.CreateWindow({
    Title = "الواجهة الاحترافية", 
    Icon = "home", 
    Theme = "Green",
    ToggleKey = Enum.KeyCode.RightShift,
})
Window:Tag({ Title = "v2.0", Color = "Blue" })

3. الأقسام والتبويبات (Sections & Tabs)

إنشاء التبويبات الداخلية والأقسام لتنظيم العناصر.

tabs.lua 
Window:Section("الرئيسي")
local Main = Window:CreateTab("الرئيسية", "home")
Main:CreateSection("عناصر أساسية")

4. الأزرار (Buttons)

إضافة زر تفاعلي مع إشعار عند الضغط.

button.lua 
Main:CreateButton("زر", "وصف", function() 
    Library.Notify("تم", "ضغطت", nil, 3, "success") 
end)

5. خيارات التفعيل والمربعات (Toggles & Checkboxes)

مفاتيح التفعيل العادية ومربعات الاختيار المخصصة.

toggles.lua 
Main:CreateToggle({ Name = "تفعيل", Default = false, Flag = "enabled", Callback = print })
Main:CreateToggle({ Name = "مربع", Type = "Checkbox", Callback = print })

6. المنزلقات (Sliders)

التحكم بالقيم العددية والسرعات.

slider.lua 
Main:CreateSlider("السرعة", 0, 100, 16, 1, print)

7. القوائم المنسدلة (Dropdowns)

القوائم الفردية والمتعددة للاختيار منها.

dropdowns.lua 
Main:CreateDropdown("قائمة", { "A", "B", "C" }, print)
Main:CreateMultiDropdown("متعدد", { "X", "Y", "Z" }, print, { "X" })

8. الاختصارات (Keybinds)

ربط الأوامر بمفاتيح لوحة المفاتيح.

keybind.lua 
Main:CreateKeybind("مفتاح", Enum.KeyCode.F, function() 
    print("F") 
end)

9. الملاحظات والنصوص (Notes, Labels & Paragraphs)

إضافة الملاحظات الملونة، النصوص التوضيحية، والفقرات الإرشادية.

texts.lua 
Main:CreateNote("ملاحظة زرقاء", "Blue")
Main:CreateNote("ملاحظة سوداء", "Dark")
Main:CreateLabel("نص بسيط")
Main:CreateParagraph("عنوان", "نص طويل يوضح شي معين", "info")

10. شريط التحميل وعرض الأكواد (Progress & Code)

أشرطة التقدم وعرض المقتطفات البرمجية.

progress_code.lua 
Main:CreateProgress("التحميل", 0, 100, 40)
Main:CreateCode("مثال", "print('hello')")

11. النوافذ المنبثقة (Dialogs)

عرض نوافذ الحوار والتأكيد للمستخدم.

dialog.lua 
Window:Dialog({
    Title = "تنبيه", 
    Content = "هل تريد المتابعة؟", 
    Icon = "info",
    Buttons = {
        { Title = "نعم", Variant = "Primary", Callback = function() end },
        { Title = "لا", Variant = "Secondary" },
    },
})

12. إدارة الإعدادات (Save & Load Config)

حفظ واسترجاع إعدادات العناصر التي تحتوي على Flags تلقائياً.

config.lua 
Window:SaveConfig("default")   -- يحفظ كل العناصر اللي لها Flag
Window:LoadConfig("default")
